# 拍摄脚本页面规范（make_cards.py）

页面 1600×1067，米色纸底。每张分镜一页，文件名 `cards/card_<id>.png`，全部页面合并为 `<出行日期>_<地点>_拍摄脚本.pdf`（地点取 `meta.place` 括号前的部分，`meta.version` 含 v2 及以上时追加 `_v2`）。

## 版式

```
┌───────────────────────────────────────────┬──────────────────────────────┐
│ 编号 | 标题                 景点 日期 镜头 │ 相机设置                     │
│                                           │  焦段光圈 / 快门 ISO / 创意外观 │
│                                           │  闪光灯 / 景别 / 机位          │
│   示意图（3:4，最大 900×897）              ├──────────────────────────────┤
│                                           │ 机位与光线示意（俯视图，北在上）│
│                                           │  风格化底图裁切 + 程序叠加      │
│                                           ├──────────────┬───────────────┤
│                                           │ 姿势与引导    │ 光线与备选     │
│                                           ├──────────────┴───────────────┤
│                                           │ 时段 · 地点 · 注意            │
│ AI 拍摄示意，非现场实拍…                   │                              │
└───────────────────────────────────────────┴──────────────────────────────┘
```

右栏区块纵坐标：相机设置 110–318；俯视图 330–690（图框 384–680）；姿势/光线 702–912（左右 40/60）；时段注意 924–1045。页脚在左下（照片下方）。

### 分镜带 `src` 时（SNS 素材驱动，v5 起）

三栏：左示意图、中来源栏、右栏（相机设置、俯视图、姿势与光线、时段注意，与上图相同）。

- 示意图区 40–700；来源栏 716–950（圆角框，内边距 14）；右栏不变。
- 来源栏从上到下：「SNS 来源」+ 编号；素材类型色块（机位帖绿、姿势帖橙、平台汇总蓝）与可复现度色块；平台 · 日期 · 赞数；原帖标题（最多 3 行）；二维码（宽 ≤ 196，机位帖与姿势帖写「扫码打开原帖」，平台汇总写「扫码打开搜索结果」）；照搬、同款姿势、也参考、现场差异四段（绿色小标题，字号 14→12 自动缩）；最下方链接（搜索页显示解码后的关键词）。
- 补充分镜（`src.ref` 为空）：标题「补充分镜」，灰色「无 SNS 素材」色块，下面写这张的作用（按 `role`）、形式（相机静帧 / 连拍 / 短片素材 / 手机实况）、景别。
- 「姿势与引导」末尾加「同款姿势：<pose_name>」。
- 示意图左上角标签：有素材写「AI 示意 · 按原帖构图的文字描述生成」，补充分镜写「AI 示意 · 补充分镜」。

### 运镜页（`tools/moves.py`）

有 `move_frames/<id>a|b|c-*.png` 三张时，上半部压到 110–520（俯视轨迹、侧视 110–320、操作要点 334–520），画面变化区 532–1030，三帧各 230×409（3:4 生图居中裁成 9:16，叠半透明三分线与 90% 安全框）；页脚写明三帧为 AI 按文字描述生成。缺帧时回到原版式与线稿三帧。

## 俯视图约定

- 底图：`basemaps/<basemap>_styled.png`（缺省 `main`；兼容旧版根目录 `basemap_styled.png`），按 `subject_latlon` 裁切 `map_window_m`（默认 84 m）宽的窗口，人物居中；窗口出界处补纸色。
- 叠加：人物（棕色圆点 + 朝向箭头）、相机（黑色矩形，标「摄影者 X m」，视觉距离最小 58 px）、背景标签（`bg_label`，白底）、太阳箭头（金色，方位取 `meta.sun[alt_time 或 time]`，标「晴天版 HH:MM 太阳 方位°/高度°」）、指北（右上）、说明文字（左上，过长自动截断加「…」）。
- `indoor: true`：不画太阳箭头与散射光箭头。
- 无 `subject_latlon` 或无底图：退回通用示意图（圆形背景弧 + 人物 + 相机 + 四向散射箭头）。
- 概略几何（`approx`）的分镜在 `topview_note` 里写明「走向为概略」。

## 图片匹配

`--images` 目录下 `*.png` 按文件名前两位与分镜 `id` 匹配（`03-水晶芒草.png` → 03）。没有图片时画占位框「示意图待生成」。

## 字体

容器：Noto Sans CJK；Windows：Microsoft YaHei。`make_cards.py` 里 `font()` 按平台查找，找不到时退回 PIL 默认字体（中文会变方块，先装字体）。

## 验收

逐页检查：文字不溢出、俯视图标签不重叠、太阳箭头方向与 `sun.md` 一致、页脚存在。
