# 模特版一页纸　箱根玻璃之森　9/28（周一）13:00 到场

服装：燕麦色粗针织开衫、内搭米白棉衬衫、深咖色灯芯绒长裙、深棕乐福鞋、棕色皮质小包；雨天透明长柄伞。备一双能湿的鞋，拍摄时换乐福鞋。
道具：透明长柄伞一把（同伴再带一把）、棕色小包、露台一杯咖啡。
妆发：雨天湿度高，发型松散半扎即可，唇色豆沙，不用亮片。
