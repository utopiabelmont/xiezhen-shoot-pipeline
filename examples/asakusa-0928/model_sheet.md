# 模特版一页纸　浅草寺　9/28（周一）10:00 到场

服装：米白色短袖针织衫、深靛蓝色阔腿长裤、白色帆布鞋、米色帆布托特包；透明长柄伞。裤脚会湿，备一条替换或选九分。
道具：透明长柄伞（主）、托特包；不用买香也可以拍 06（站香炉旁即可）。
妆发：雨天湿度高，发型松散半扎；唇色豆沙；不用亮片。
