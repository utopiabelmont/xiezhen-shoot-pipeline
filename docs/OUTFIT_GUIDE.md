# 穿搭基本法（阶段 2b：按场地色、SNS 与天气定一套衣服）

给阶段 2b「穿搭」用。输入是 `palette.json`（场地主色）、`spots_social.md` 的穿搭观察、`sun.md` 的天气与季节、分镜的动作需求；产出 `outfit.json` + `outfit.md`，由 `make_outfit_page.py` 渲染成小抄 PDF 的第一页，`pipeline.py lint` 检查其中两条可算的规则。规则来自人像教学里反复出现的几条共识（来源见文末）。

## 1 先定路线，再选衣服

看场地色卡的前三个主色，三选一：

| 路线 | 做法 | 适用 |
|---|---|---|
| 同系色（融） | 服装取场地主色的同一色相，用明度差拉层次（浅衣深景、深衣浅景） | 编辑感、氛围优先；石材、木、雾、水这类灰调场地 |
| 邻近色（稳） | 服装在色环上与场地主色相邻 30–60°，饱和度略低于场地 | 大多数庭园、寺社、街区 |
| 补色点缀（跳） | 服装主体中性色，用一件小面积补色（围巾、伞、包）对场地主色 | 场地单色、灰、雾、阴天；想让人从背景里跳出来 |

判断依据：场地色彩多而杂（红叶、花田、灯笼街）就穿纯色中性；场地灰而单（石材、雾、阴天水面）服装可以带一点饱和。

## 2 可算的两条（lint 会检查）

- 全身不超过 3 个主色；点缀色（伞、包、发饰）标 `accent: true` 不计。
- 服装主色与场地前四个主色的 ΔE（CIE76）不小于 12；小于 12 会融进背景。有意为之（比如背影远景要「人在景里」）就在该色上标 `blend_ok: true`。ΔE 12–22 属于偏近，靠明度差解决，穿搭页会标出来。

## 3 几条不算但要守的

- 红叶、黄叶季用比环境亮一档的土色（燕麦、米白、浅驼），深棕深绿会被吃掉。
- 阴天、夜景、深色室内：脸旁放一块亮色（围巾、衬衫领、浅色外套），否则脸和背景一起沉。
- 强色背景（朱红门、靛蓝暖帘、绿墙）避免纯白和纯黑，用米白、炭灰。
- 避免细条纹、密格纹（摩尔纹）、大 logo、亮片与强反光面料、透视色差大的化纤。
- 和创意外观配合：全组 IN（低饱和）时，服装靠明度差分离；FL（保色）时，可以留一处饱和点缀让它被保住。
- 裙长与动作：走动、转身、连拍用长裙或阔腿裤；坐、蹲、台阶用裤装或中长裙；风大不用轻薄短裙。
- 一套主装 + 一件可换层次（外套、针织、围巾）+ 道具解决手的位置（伞、杯、包、扇）。改版只换层次和道具，不换主装，保证全组一致。
- 鞋要能走两小时；园区台阶、木栈道、湿石板不用细跟。
- 天气替换：雨天透明伞 + 防水鞋 + 深色下装；晴天硬光加一件浅色外层做反光板，帽檐压眼睛。

## 4 从 SNS 里看什么

在 `spots_social.md` 的「穿搭」栏记：出片帖里主流穿什么颜色（决定本组要不要避开）、有没有场地限制（寺社不露肩、美术馆不带大包）、当季游客的颜色倾向（红叶季满园橙红时，米白最跳）。

## 5 outfit.json 怎么写

见 `templates/outfit_template.md`。`colors` 里每个色写 hex、名字、用在哪个部位；`per_shot` 给每张分镜一句着装提醒（露不露围巾、伞开不开、外套脱不脱）。

## 来源

- 数码摄影网「人像摄影如何玩转人物服装与场景的色彩搭配」：同系色融合、补色冲击、场景杂则服装中性、场景灰则服装饱和。
- あかうさ「衣装の色×背景色を考えるだけで作品は変わる」：補色是背景大面积、服装做点缀；同系色求统一。
- shikisaiphoto「ポートレート撮影で映える服装の選び方」：季节色、红叶季用亮一档、夜景脸旁放亮色、强色背景避纯白纯黑、裙长与动作。
