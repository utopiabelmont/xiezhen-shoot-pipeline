# outfit.json / outfit.md 模板（阶段 2b 穿搭）

先跑 `pipeline.py palette <plan>` 得到场地主色，再按 `docs/OUTFIT_GUIDE.md` 选路线、写 `plans/<plan>/outfit.json`；`pipeline.py cards` 会把它渲染成 PDF 第一页（`cards/outfit_01.png`，逐张提醒多时另出 `outfit_02.png`）。`pipeline.py lint` 检查：主色 ≤ 3、与场地主色 ΔE ≥ 12。
