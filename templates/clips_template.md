# clips.md 模板（短片剪辑单）

出发前按分镜里 `medium: video` 的条目填好顺序；回家剪辑照这个单子。规则见 `docs/VIDEO_NOTES.md` 第 7 节。

| 序 | 分镜 | 角色 | 模式 | 运镜 | 实录 | 起 → 止 | 转场（与下一条） |
|---|---|---|---|---|---|---|---|
| 1 | 25 | closing 片尾（放最后） | 24p | 后拉上摇 | 5 s | 背影站定 → 退到 8 m 上摇 | 结束 |
| … | | | | | | | |

- 成片长度：30–60 秒，8–12 条；升格放中段做换气。
- 转场优先用同一遮挡物（柱、伞、叶）接，其次硬切，不用叠化。
- 音乐节拍：实时片段卡拍剪，升格片段跨拍。
- 手机实况不进短片，单独发。
