# 穿搭（全天一套）

**全天一套：月白盘扣短衫 · 燕麦长裙 · 墨绿开衫**

路线：邻近色（稳）：四个景点分别是青灰与深褐（石鼓）、奶油黄与墨绿（保卫里）、灰白天光下的招牌色块（解放路）、灰绿江水与暖色灯笼（东洲岛）；服装取低饱和的月白与燕麦，靠明度从深色木构、黄墙与江面里分出来，下午加一件墨绿开衫压住层次

## 主方案

- top：月白色（极浅灰蓝白）哑光缎面新中式短衫，小立领，同色布盘扣，袖到小臂
- layer：墨绿色细针织开衫，敞开穿（解放路后半段起与东洲岛全程；冷或下雨时穿）
- bottom：燕麦米色哑光长半身裙，A 字微摆，裙长到小腿中段，走路与蹲下都方便
- shoes：米白色平底玛丽珍鞋（防滑底），台阶、礁石与湿木地板都能走
- accessories：浅色木簪一支；不戴大耳饰
- bag：深棕色小号皮质斜挎包

全身 3 色 + 深棕一处点缀；全天不换主装，只在下午加墨绿开衫，换道具：石鼓折扇 → 保卫里雏菊 → 解放路透明伞与小吃 → 东洲岛透明伞。

## 替换方案

- 雨天：透明长柄伞 + 防滑平底鞋；裙摆过湿时卷起一折再拍全身
- 冷：早上 17 °C、晚上 20 °C：墨绿开衫随身，不再加新颜色
- 晴：去掉开衫，月白短衫在顺光下会偏亮，曝光 −0.3

## 道具与妆发

- 檀色竹骨折扇（石鼓书院、东洲岛）
- 一小束黄色雏菊（保卫里，石鼓书院出来后路边花店买或提前备）
- 透明长柄伞（解放路、东洲岛，兼作雨具）
- 纸巾（垫台阶与长椅）
- 妆发：深棕长发低盘发，一支浅色木簪，耳侧留两缕碎发；清透薄底妆，浅杏腮红，豆沙红哑光唇；下午补一次定妆，雨天备吸油纸

## 避免

纯白（红墙与黄墙前发灰）、纯黑（灯笼与夜色里脸会沉）、细条纹与密格纹（手机摩尔纹）、大 logo、亮片与强反光面料、高跟鞋（台阶、礁石、湿木地板）

## 理由

- 石鼓书院 SNS 主流是浅色旗袍与新中式，月白盘扣短衫贴合书院的书卷气，深褐格扇门前明度对比最强
- 保卫里的墙是奶油黄与红，月白与燕麦不会被吃掉，墨绿开衫与绿皮车厢同色系呼应
- 东洲岛阴雨的灰绿江面与暖色灯笼之间，墨绿开衫让脸旁有层次，月白领口把脸托亮
- 场地色卡没有 Commons 照片可抽（palette 阶段为 0 张），本页颜色按 SNS 帖子与现场常见色判断

## SNS 穿搭观察

石鼓书院：汉服、新中式、浅色素裙最多；保卫里：浅色简约、复古、牛仔，避开深色复杂花纹；东洲岛：浅色长裙、新中式、旗袍；解放路夜景帖偏港风深色，本组白天不换装，只加开衫。
