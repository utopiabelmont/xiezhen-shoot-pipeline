# 分镜表模板（拍摄小抄的数据层）

一次外拍至少 9 张。每张一条记录，字段齐全后才编译写真 prompt 与小抄页面。
光线三栏的数值来自 `plans/<批次>/sun.md`，spot 与背景方位来自 `spots.md` 和网页调研。

| 字段 | 填写内容 | 来源 |
|---|---|---|
| 编号 / 标题 | 01　光之回廊 · 环境人像 | 自定 |
| 地点（spot） | 园内位置、到达路径、是否需门票/排队 | spots.md + 网页调研 |
| 背景方位 | 背景主体在人物的哪个方位（如：拱顶在人物北侧，水面在西侧） | 网页调研 / 地图 / Commons 照片 |
| 推荐时段 | 具体时刻区间，如 15:30–16:10 | sun.md 逐时表 + 天气表 |
| 太阳位置 | 方位角与高度角，如 西南西 249°，高度 24° | sun.md |
| 光型 | 顺光 / 前侧光 / 侧光 / 后侧光 / 逆光；硬光 / 薄云柔光 / 阴天散射 | sun.md 人物朝向表 + 天气表 |
| 人物站位与朝向 | 站在哪、脸朝哪个方位（与太阳夹角） | 由光型反推 |
| 景别 | 特写 / 近景（胸口以上） / 半身 / 七分 / 全身 / 环境远景 | 组内分配，9 张至少覆盖 4 种 |
| 焦段与光圈 | 只从手上镜头选，如 24-105 F4：35mm F4 / 85mm F4 / 105mm F4 | 景别 + 拍摄距离反推 |
| 快门 / ISO | 静态 1/250 自动 ISO；走动 1/500；阴天可提 ISO | 光质 |
| 机位 | 高度（腰/胸/眼平/低机位/俯拍）、角度（正面/侧前方 45°/侧面）、距离（米） | 景别 + 焦段 |
| 前景 / 背景处理 | 前景遮挡物、背景保留到什么程度（不要全虚化 / 压成色块） | skill 背景信息层级 |
| 动作与表情引导 | 一句能直接对模特说的话，含触发事件 | skill 人物事件 |
| 备选 | 晴天版 / 阴天版 / 雨天版各一句：站位或时段怎么改 | 天气表 |
| 注意事项 | 人流、禁止三脚架、不进装置区、地面湿滑 | 网页调研 |

## 一条填好的示例（用 2026-09-27 箱根样本数据）

- 编号 / 标题：06　玻璃前景 · 眼神近景
- 地点：光之回廊北侧步道，回廊拱顶在人物南侧约 3 m
- 推荐时段：15:30–16:10
- 太阳位置：西南西 249°→254°，高度 24°→18°（sun.md）
- 光型：人物面朝西北时为前侧光；当日预报 15–16 时云量 54–69%、直射比约 0.12–0.19，实际为阴天散射光，方向感弱，可把回廊玻璃当作反射补光面
- 人物站位与朝向：站在步道靠回廊一侧，身体朝西北，脸略向西（太阳侧）转 20°
- 景别：近景，胸口以上
- 焦段与光圈：105mm F4，距离 1.5–2 m
- 快门 / ISO：1/250，自动 ISO（阴天上限 3200）
- 机位：眼平，侧前方 30°，前景放少量失焦玻璃串
- 前景 / 背景：前景玻璃只占画面一角，背景树丛压成绿色大形
- 动作与表情引导：「风把碎发吹到眼前了，抬手拨到耳后，顺势看我旁边一点」
- 备选：晴天时同一站位改成人物朝西南 30°做后侧光，玻璃出高光点；雨天改到回廊内侧屋檐下，机位不变
- 注意事项：只在步道取景，不靠近装置；阴天 16:30 后光量下降快

## shotlist.json 字段（完整定义见 shotlist_schema.json，示例见 shotlist_example.json）

- `subject_latlon`: [纬度, 经度]，有此字段时俯视图用风格化底图裁切并按坐标叠加站位；没有时画通用示意图
- `cam_bearing` / `cam_dist` / `face_bearing` / `bg_bearing` / `bg_label`：相机方位角（度，正北 0）、机位距离（米）、人物脸朝向、背景方位与标签
- `alt_time`: 晴天版建议时刻（HH:MM），俯视图的太阳箭头按此时刻取 meta.sun；缺省取 `time` 里第一个时刻
- `basemap`: 用哪张底图（`basemaps/<name>_styled.png`），缺省 main；园外备选点用各自底图
- `map_window_m`: 俯视图裁切宽度（米），缺省 84；大场景可放宽到 110
- `indoor`: true 时不画太阳箭头与散射光箭头（室内展厅）
- `topview_note`: 覆盖俯视图底部的天气说明（园外备选点、室内点用）
- `look` / `flash`: 创意外观与闪光灯建议，直接显示在相机设置栏
- `meta.sun`: {"HH:MM": [方位, 高度]}，建议从 sun.json 的 rows 取整点与半点
